# Authoring CourseKit pages

This section is for **course authors**, who work with semantic XML and course configuration, not framework internals.

1. [Get started](/guide/getting-started) and [configure bootstrap](/guide/bootstrap).
2. [Write semantic XML](/guide/authoring), using the [semantic XSD catalog](/reference/semantic-xsd) and [page parameters](/reference/page-parameters).
3. Browse the [semantic-to-page mappings](/reference/xml-mappings) to understand what the page transform produces.
4. Adjust site-level styles using tokens and documented component interfaces; [CSS conventions](/reference/css-conventions) distinguish framework requirements from site recommendations.

Do not write visual `p:*` output XML as the normal content-authoring interface; page transformations produce it.
